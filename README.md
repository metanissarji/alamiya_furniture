# רהיטי עאלמיה · العالمية للأثاث

Website for Alamiya Furniture — sofas, sectionals and dining sets, locally made. Showroom in Ein Ibrahim, Umm al-Fahm.

- Static site: `index.html` + `img/`, no build step.
- Hebrew by default, with an Arabic toggle (both RTL).
- WhatsApp number is set in `WA_NUMBER` at the top of the script in `index.html`.

Local preview: open `index.html` or run any static server in this folder.
